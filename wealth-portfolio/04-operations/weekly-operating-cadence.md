# Weekly Operating Cadence (your 1–10 hrs/week, structured)

The plan only works if the time is *structured*. This is your family-office operating rhythm. Total:
**~5–8 hrs/week** in the build phase, trending down as automation takes over.

## The non-negotiable: 2 hours of outreach/week (first 90 days)
Block it on the calendar. It is the highest-leverage activity in the entire portfolio and the one
thing that can't be fully automated early. Protect it like a client meeting.

---

## Weekly schedule (template)

### Monday — Review & Aim (45 min)
- [ ] Read the auto-generated **Weekly KPI Roll-Up** (BP-09): numbers vs. targets.
- [ ] Read the **Continuous-Improvement action list** (Agent #9): pick the top 1–2 items for the week.
- [ ] Set the week's 3 priorities. Write them down.

### Tuesday/Thursday — Outreach blocks (1 hr each = 2 hrs)
- [ ] Review the AI-drafted outreach queue (BP-06); personalize and send 5+.
- [ ] Respond to replies; book discovery calls.
- [ ] Run any scheduled discovery calls (15–20 min each).
- [ ] Send same-day SOWs to anyone who's ready (Agent #3 drafts).

### Wednesday — Delivery (1–3 hrs, scales with client count)
- [ ] Build/clone workflows for new clients (SOP-02).
- [ ] Monthly tune-ups due this week (SOP-04).
- [ ] Clear the support triage queue (Agent #4 has pre-sorted it).

### Friday — Improve & Allocate (45 min)
- [ ] Approve/auto-send monthly client reports due (BP-07).
- [ ] Action ONE continuous-improvement item (tighten a template, automate a manual step).
- [ ] Update the financial dashboard; run the **capital-allocation waterfall** on any profit
      distributions (route to portfolio / reinvest per `05-finance/`).
- [ ] Capture any case study from the week (SOP-05).

### Monthly (1 hr, last Friday)
- [ ] CFO Agent (#7) review: P&L, MRR, churn, runway vs. plan.
- [ ] Execute portfolio contribution (Build 3) per waterfall.
- [ ] SaaS decision-gate check once you have ≥3 clients (Agent #8).

### Quarterly (2 hrs)
- [ ] Portfolio rebalance check (IPS §5).
- [ ] Re-price / raise rates for the service if demand supports it.
- [ ] Review the full opportunity scorecard — promote/demote/archive bets.
- [ ] Read failed-experiment log; double down on winners.

---

## Phase shifts (how the hours change over time)
| Stage | Your weekly hours | What changed |
|---|---|---|
| Months 1–3 (launch) | 8–10 | Heavy outreach + first builds, manual. |
| Months 4–6 (systematize) | 6–8 | Templates + VA + agents absorb routine work. |
| Months 7–12 (scale) | 4–6 | Automation runs delivery; you do sales + improvement. |
| Year 2+ (operate) | 2–5 | You manage the system, not the tasks. |

The explicit goal: **every month your hours/client fall.** If they don't, the continuous-improvement
loop has found your next project.
